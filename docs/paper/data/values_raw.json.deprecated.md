# Deprecated values_raw.json

`values_raw.json` was an intermediate macro-dump file from an earlier paper pipeline. The active LaTeX build reads `docs/paper/latex/values.tex`; newer pipeline runs write generated macro overrides to `values.generated.json`.

This file name is kept only as a deprecation marker to prevent the old 175/175 split and 10--200 Hz wording from being reused.
