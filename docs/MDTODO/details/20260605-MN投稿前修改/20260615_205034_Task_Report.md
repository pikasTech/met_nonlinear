# R2.2 任务报告：MN 投稿系统调查与流程清单

调查时间：2026-06-15

## 结论

`Microsystems & Nanoengineering`（MN）目前从 Nature 期刊页跳转到 Springer Nature 的 `Manuscript Tracking System` 投稿，入口是：

- MN Online Submission: https://www.nature.com/micronano/authors-and-referees/online-submission
- MN Manuscript Tracking System: https://mts-micronano.nature.com/cgi-bin/main.plex
- 系统公开作者说明: https://mts-micronano.nature.com/cgi-bin/main.plex?form_type=display_auth_instructions
- MN Guide for Authors: https://www.nature.com/documents/micronano-gta.pdf

截至本次调查，Guide for Authors 的页面版 PDF 显示为 `Revised June 12th, 2026`，比仓库早先记录的 `2026-01-22` 版本更新。投稿前应以该 2026-06-12 版本和在线系统实时页面为准。

系统内投稿流程公开说明为 4 个主任务：

1. `Files`
2. `Manuscript Information`
3. `Validate`
4. `Submit`

## 需要提前准备的信息和文件

### 作者与账号

- 提交人或通讯作者需要能登录 MN Manuscript Tracking System；系统首页提示需要浏览器接受 cookies。
- 如尚无账号，需要先注册 Springer Nature / MTS 账号。
- 建议通讯作者提前在 Springer Nature 账号中关联 ORCID；Springer Nature 支持在创建账号或投稿过程中添加 ORCID。
- 每位作者需要准备：
  - First name / middle initial / last name
  - Postal address
  - E-mail address
  - 作者单位信息，包含 city、state、country、zip code
  - 官方邮箱
- 通讯作者额外需要：
  - Telephone number
  - Fax number，如系统要求
  - Full contact details
- MN Guide 明确要求所有作者已同意投稿，并且通讯作者对投稿决定承担最终责任。

### 稿件类型与篇幅

当前稿件应按 `Article` 准备，而不是 Brief Report。

Article 关键限制：

- Abstract：非结构式，最多 250 words。
- Main text：约 6000 words，不含 abstract、references、figures、tables。
- Tables/Figures：最多 8 个。
- References：最多 50 条，且尽量使用最新文献。
- 正文结构顺序：
  - Introduction
  - Results
  - Discussion
  - Materials and methods

Guide 说明 word limit 是指导性限制，编辑会结合审稿反馈考虑超限稿件；但投稿前仍建议按上述限制收口，避免格式初筛风险。

### Cover letter

每次投稿必须附 cover letter。至少应包含：

- 全体作者同意投稿。
- 稿件未以完整、部分、其他形式或其他语言发表或正在他处投稿。
- 没有复用外部来源材料；如果复用了，说明已获得授权并随稿提交授权文件。
- Conflict of Interest statement。

### 主文稿件文件

Guide 说明初投不强制必须完全排成 MN 版式，只要能供编辑和审稿人评估即可；但它同时要求：

- 使用常见文字处理软件准备稿件文本，示例为 Microsoft Word。
- Supplementary Information 单独提交，不能合并进主文文件。
- 主文应以 single file 提供，figures 和 tables 放在正文适当位置。
- 稿件若原则上接收，必须提供 Microsoft Word 文件。
- 主文文件顺序应包含：
  - Title page
  - 对应文章类型要求的正文部分
  - References
  - Acknowledgements，可选
  - Author Contributions
  - Conflict of Interest statement
- 主文应包含连续行号。
- Title page 标题少于 200 characters，并包含作者全名、单位、官方邮箱和通讯作者完整联系方式。

对当前仓库的含义：

- 仅有 LaTeX/PDF 不够稳妥；初投可用 PDF 供评审，但应尽快准备一个可编辑的 Word 主文或确认系统是否允许当前 LaTeX 源作为主文文本。
- `supplement.tex` / supplement PDF 应作为 Supplementary Information 独立文件上传。
- 如果继续用 LaTeX 生成 PDF，主文投稿 PDF 中仍应包含连续行号、title page、声明区和 Supplementary Information 固定声明。

### Supplementary Information

Supplementary Information 是同行评审材料，必须通过投稿系统随稿提交；接收后不能再随意修改或新增。

准备要点：

- Supplement 必须增强理解，但主文在没有 Supplement 的情况下也应完整自洽。
- Supplement 单独作为 Word 或 PDF 文件提交，Guide 更偏好 Word。
- 主文末尾、参考文献之前，应加入固定 Supplementary Information 声明。
- 如果 Supplement 包含视频、图片或非文本文件，应另备说明文本或 legends list。
- 可接受格式包括 PDF、Word、Excel、plain text、TeX/LaTeX、图片、视频、声音等。

### 数据、代码与声明

Article 必须提前准备：

- Data availability statement，放在 Methods 末尾，若有 code availability，应位于 code availability 之后。
- Code availability statement，如果稿件依赖代码支撑结论，建议明确给出仓库、归档 DOI 或可用性说明。
- Author contributions。
- Conflict of Interest / Competing Interests，Guide 要求在 manuscript、cover letter、投稿系统中都出现。
- Acknowledgements 和 funding 信息。
- 如使用第三方图片、表格、长引文或已发表材料，提前准备书面授权文件。

### 图片、表格和源文件

初投系统公开说明建议：

- Article file 不嵌图时尽量小于 1-2 MB。
- Figure files 总量尽量小于 2-3 MB。
- 每张图约 100-300 KB 可满足系统初步转换。
- 图号应写入每个 figure 文件的 title line。
- 避免上传加密文件，系统不能转换 encrypted files。
- 如果系统转换某些文件失败，等待转换引擎尝试完成；公开说明提到失败多次后可上传 PDF 版本作为 fallback。

Guide 的生产阶段图件要求更高：

- 接收后每个 figure 应单独文件提交。
- 多子图合成一个 figure 文件。
- 优先原始矢量格式，接受 AI/EPS/PS/PDF。
- 含照片或仪器图片的矢量图中，图像部分建议 300+ dpi、宽度 2000+ pixels。
- 每个 figure file 需小于 100 MB。
- 统一字体 Arial、Helvetica 或 Times New Roman。

### 推荐/回避审稿人

系统公开说明要求可提前准备 suggested 和 excluded reviewers 的 contact information：

- Name
- E-mail address
- Institution

建议本稿至少准备 3-5 位建议审稿人和必要的回避审稿人名单，避免临到系统页面时再找。

### APC 与开放许可

MN 是开放获取期刊。当前官网 APC 页面显示：

- Brief Report：GBP 1395 / USD 1895 / EUR 1645
- All other article types：GBP 2790 / USD 3790 / EUR 3290

当前稿件按 Article 估算，应按 `All other article types` 预算。APC 价格以接收日期决定，可能叠加 VAT 或本地税费。

如需申请 waiver / discount，应在投稿时提出；官网说明审稿中或接收后再申请通常不能被考虑。

## 系统内投稿流程清单

### 0. 进入系统

1. 打开 MN Online Submission 页面。
2. 点击 `journal manuscript tracking system` / `Submit manuscript`。
3. 进入 `https://mts-micronano.nature.com/cgi-bin/main.plex`。
4. 确认浏览器允许 cookies。
5. 登录账号；无账号则注册。
6. 在系统 Home 页面点击 `Submit Manuscript` 开始。

### 1. Files

目标：上传所有稿件文件并设置合并顺序。

操作清单：

- 上传主文文件。
- 上传 figures / tables / videos。
- 上传 Supplementary Information，注意不要合并进主文。
- 上传 cover letter；公开说明注明 cover letter 不会提供给 reviewers。
- 如有版权授权文件，一并准备上传。
- 对每个图文件标清 figure number。
- 在 completion screen 指定所有文件在 merged document 中的顺序。
- 等待系统转换并生成 PDF。
- 如果转换失败，检查是否为加密文件、非支持格式、文件过大或字符编码异常。

验收：

- merged PDF 顺序正确。
- 主文、图、表、Supplement 都可在系统中看到。
- 文件没有乱码、缺页、空白页或图表错位。

### 2. Manuscript Information

目标：填写稿件元数据、作者信息和系统声明。

操作清单：

- 选择 manuscript type：Article。
- 粘贴 title。
- 粘贴 abstract。
- 填写所有作者信息。
- 通讯作者信息填写到 corresponding author fields；系统公开说明特别提醒不要把同一通讯作者再重复录入 contributing author fields。
- 填写稿件相关信息和文件类型/数量。
- 填写 suggested reviewers / excluded reviewers。
- 填写 Conflict of Interest / Competing Interests。
- 填写或确认 data availability / code availability 等系统字段。
- 如系统询问 OA license、APC funding、waiver/discount，需要按实际预算和资助情况选择。

验收：

- 作者顺序、单位、邮箱和通讯作者标记与 title page 完全一致。
- 标题和摘要与最终稿一致，无复制粘贴乱码。
- 所有声明与主文、cover letter 一致。

### 3. Validate

目标：提交前审核系统生成的所有信息和 PDF。

操作清单：

- 下载或打开 merged PDF。
- 检查 title page、abstract、正文、图表、references、声明区。
- 检查 Supplement 是否作为独立文件存在。
- 检查 line numbers 是否连续。
- 检查图表引用顺序和 figure/table 顺序。
- 检查希腊字母、上标、单位、公式、参考文献编号是否转换正常。
- 对任何错误点击 `Change` 或 `Fix` 返回修改。
- 确认 merged PDF 和任何未合并 PDF 均可接受。

验收：

- 无系统红框或红箭头提示。
- mandatory fields 全部完成。
- merged PDF 可以作为审稿文件阅读。

### 4. Submit

目标：最终批准并提交稿件。

操作清单：

- 进入 `Submit` 主任务。
- 等待系统执行 mandatory-field final check。
- 对被红框/红箭头标出的字段逐项 `Fix`。
- 最终点击 `Approve Submission`。
- 等待 author desktop 出现 `Manuscript Approved` 类确认信息。
- 保存 manuscript tracking number、确认邮件、提交时间和系统生成 PDF。

验收：

- 系统显示提交成功。
- 对应邮箱收到确认邮件。
- 稿件出现在 MTS 或 Springer Nature Profile 的 submission/status 区域。

## 提交后跟踪

可通过两条路径跟踪：

- 登录 MN Manuscript Tracking System，在稿件 tracking number / abbreviated title 页面点击 `Check Status`。
- 登录 Springer Nature Profile，在 `Your research` 区域查看 Submitted / Published。

Springer Nature 支持页将提交后编辑流程概括为：

1. Initial quality check：检查作者、competing interests、ethics approval、plagiarism 等。
2. Editor assigned：通过初筛后分配 Editorial Board editor。
3. Peer review：审稿人检查技术可靠性、科学有效性、方法、分析、解释和数据支撑。
4. Decision：accept、minor/major revision、reject；拒稿时可能考虑 article transfer。

技术问题应联系 Platform Support Helpdesk，不建议把系统登录、上传、转换故障直接发给 editorial office。Guide 最后一页给出的一般咨询邮箱是 `mine@aircas.ac.cn`，适合非系统故障类问题。

## 修回与接收后

### Revision

修回时需要准备：

- Rebuttal letter：逐点回应 reviewer comments；不同意时给出充分理由。
- Marked-up manuscript：高亮或标记所有修改。
- Clean manuscript：无高亮的干净稿。

### Acceptance / production

接收后：

- Guide 说明约 7-10 个工作日内通讯作者会收到 APC payment form 链接。
- 随后通讯作者需要代表全体作者完成 open access Licence to Publish。
- Proofs 不会在相关表单完成前发送。
- Proof correction 收到后需在 48 小时内返回；此阶段不能做大范围改动。

## 当前投稿前最小可执行清单

### 必须补齐

- 通讯作者 MTS / Springer Nature 账号确认。
- 通讯作者 ORCID 关联确认。
- R2.1 作者信息更新完成后，同步 title page、投稿系统作者字段、cover letter。
- Article 类型最终确认。
- 250-word unstructured abstract 最终版。
- 主文 6000-word / 8 display items / 50 references 约束复核。
- 连续行号版本主文。
- Cover letter。
- Data availability statement。
- Code availability statement。
- Author contributions。
- Conflict of Interest / Competing Interests。
- Acknowledgements / funding。
- Supplementary Information 独立文件。
- 推荐/回避审稿人名单。
- APC 预算和 waiver/discount 是否申请的决定。

### 当前仓库材料映射

- 主文 LaTeX 源：`docs/paper/latex/main.translated.tex`
- 主文 PDF：`docs/paper/latex/build/main.translated.pdf`
- Supplement 源：`docs/paper/latex/supplement.tex`
- Supplement PDF：`docs/paper/latex/build/supplement.pdf`
- 参考文献库：`docs/paper/latex/nonlinear.bib`

风险点：

- MN Guide 明确偏好 Word 主文，并说明原则接收后需要 Word 文件；因此最终 live submission 前最好准备 Word 主文，或至少确认系统当前是否接受 LaTeX/PDF 初投。
- Supplement 接收后不再编辑，必须在初投前做最终自查。
- Conflict of Interest 同时出现在 cover letter、manuscript 和 submission system，三处措辞必须一致。
- 若申请 APC waiver/discount，必须在投稿点提出。
