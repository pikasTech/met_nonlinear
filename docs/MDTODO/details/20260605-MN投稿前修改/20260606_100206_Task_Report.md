## 当前主要问题判断

### 1. 标题仍把 AI 放在主语位置

当前标题：

```tex
\title[On-Board Real-Time AI Compensation for MET]{On-Board Real-Time AI Compensation for Nonlinear Drift in Electrochemical Seismometers}
```

问题：
- `AI Compensation` 是题目第一信号，容易让文章看起来像通用 AI 算法稿。
- `compensation system` 没有明确出现，弱化了“带硬件的整体系统”。
- `nonlinear drift` 比较宽泛，本文最核心的物理问题其实是 `nonlinear frequency-response drift` 或 `amplitude-dependent frequency-response drift`。

根据后续确认，标题应在原题基础上最小修改，只加入 `System`，避免改变过多：

```tex
\title[On-Board AI Compensation System for MET]{On-Board Real-Time AI Compensation System for Nonlinear Drift in Electrochemical Seismometers}
```

保留的备选标题仅作为风格参考，不作为下一轮优先方案：
- `On-Board Real-Time AI Compensation System for Nonlinear Frequency-Response Drift in Electrochemical Seismometers`
- `On-Board Real-Time Wiener-KAN Compensation System for Nonlinear Drift in Electrochemical Seismometers`

推荐采用最小修改版。它同时满足：
- 主语是 compensation system；
- 保留原题的 `On-Board Real-Time AI Compensation` 识别度；
- 不额外引入 `hardware-integrated` 或 `frequency-response drift` 等较大标题改动；
- AI 通过 `Compensation System` 归入系统服务位置。

## 摘要修改计划

### 当前摘要问题

当前英文摘要在第一半段中写到：

```text
Traditional force feedback methods risk closed-loop oscillation at large magnitudes, while data-driven deep learning methods ... struggle to meet real-time requirements ...
To overcome edge-compute limitations and force feedback instability, this paper proposes Wiener-KAN...
Furthermore, this paper constructs and releases the first three-dimensional frequency response dataset...
```

问题：
- `force feedback` 和 `edge-compute limitations` 被放在摘要前部，抢了主线。
- `edge-compute` 不符合反馈要求，应从摘要中删除。
- 数据集说明出现过早，容易把数据集写成核心创新，而不是训练和验证支撑。
- 当前摘要把 `dataset / Wiener layer / KAN / AFMAE / LUT / STM32` 并列展开，创新点显得偏散。
- 结尾有 `potential for generalization to other sensors`，外延略大；可以保留为很弱的展望，也可以删去，优先把结尾收束到 MET 实时补偿系统。

### 推荐摘要句序

摘要建议压缩为 6 个逻辑单元：

1. **器件问题**：MET 对宽频带、高动态范围地震探测重要，但大震级下机械-流体-电化学耦合导致幅值相关频率响应漂移。
2. **系统目标**：需要一个保持传感器硬件结构、能够实时运行的前馈补偿系统。
3. **核心方案**：提出 hardware-integrated Wiener-KAN compensation system。
4. **方法机制**：用震级条件局部频率响应初始化 Wiener 线性层，用带符号与对称性条件的 KAN 表达剩余幅值相关非线性，并将样条映射预计算为 LUT。
5. **训练与验证支撑**：在后半段说明三维频率响应数据集和 AFMAE，用作系统训练与频域一致性评价支撑。
6. **量化结果**：给频率漂移、灵敏度漂移、线性度误差、STM32F405 吞吐率和 RAM 占用，结尾落到 MET real-time nonlinear compensation。

### 摘要中应删除或后移的内容

删除：
- `edge-compute limitations`
- `edge AI`
- 摘要中直接把数据集称为最核心创新的表达

后移：
- force feedback 的闭环振荡风险：放在“前馈系统优势”附近，用一句话交代即可。
- dataset：放在方法后半段，作为训练和验证基础。
- AFMAE：与 dataset 一起放到训练目标和频域评价支撑里。

### 推荐英文摘要骨架

以下不是本轮直接替换文本，而是下一轮改稿可采用的句级骨架：

```text
Electrochemical seismometers are promising sensors for broadband and high-dynamic-range seismic monitoring, but magnitude-dependent coupling among mechanical, fluidic, and electrochemical processes shifts their frequency response and degrades waveform fidelity at large inputs.
Here we present a hardware-integrated Wiener-KAN compensation system for real-time feedforward correction of nonlinear frequency-response drift in electrochemical seismometers.
The system initializes a multi-kernel Wiener linear layer with magnitude-conditioned local frequency-response slices and uses a sign- and symmetry-constrained Kolmogorov-Arnold network to map the residual amplitude-dependent nonlinearity.
After training, the spline mappings are precomputed as lookup tables, enabling point-wise on-board inference without adding mechanical force-feedback hardware.
To train and evaluate the system, we construct a three-dimensional frequency-response dataset over frequency and magnitude and use an amplitude-frequency mean absolute error to align waveform learning with frequency-response accuracy.
With the input magnitude expanded by over \valInputGainExpansion~$\times$, Wiener-KAN reduces frequency drift from ... to ..., sensitivity drift at ... from ... to ..., and linearity error from ... to ....
The exported implementation achieves ... points/s and ... KB RAM on an STM32F405 microcontroller, supporting real-time nonlinear compensation of electrochemical seismometers.
```

中文摘要应按同一顺序回填，保持 CNEN 两侧结构一致。

## 创新点修改计划

### 当前贡献陈述问题

当前 Introduction 末段写法：

```text
the contribution of this work is organized around data, model, loss, and deployment
```

问题：
- 四项并列使创新点显得分散。
- `data` 被放在第一层，容易和杨老师反馈中的“数据集说明不属于核心创新”冲突。
- MN 范文更强调“一个微系统问题如何被系统方案解决”，而不是把算法组件平铺。

### 推荐收敛为三层贡献

建议把创新点压缩为：

1. **System contribution**：面向 MET 幅值相关频率响应漂移的硬件集成前馈补偿系统。
2. **Model contribution**：Wiener 局部频率响应先验 + 带符号与对称性条件的 KAN，用于处理频域动态骨架与幅值相关非线性。
3. **Evaluation and deployment contribution**：三维频率响应数据集、AFMAE、LUT 和 STM32F405 实测共同构成训练、验证和板端部署链路。

数据集和 AFMAE 放入第三层，作为 evaluation/deployment chain 的支撑，而不是第一贡献。

### Introduction 末段建议改写方向

建议替换当前第 166 行附近贡献段，改为一个连续段落或三句式贡献段：

```text
The main contribution of this work is a hardware-integrated Wiener-KAN compensation system for real-time correction of amplitude-dependent frequency-response drift in electrochemical seismometers. The system combines magnitude-conditioned Wiener linear kernels with a sign- and symmetry-constrained KAN, allowing local frequency-response priors and trainable static nonlinear mappings to operate in one feedforward compensator. A frequency--magnitude response dataset, the AFMAE training objective, LUT-based C export, QEMU numerical checks, and STM32F405 measurements jointly evaluate both compensation accuracy and on-board feasibility.
```

这样可以把创新点集中为“系统”，再展开模型和验证链路。

## 结论同步修改计划

当前 Conclusion 的问题：
- 首句是 “constructs the Wiener-KAN nonlinear compensation framework by combining ...”，仍偏算法拼装。
- 第二句连续罗列 dataset、Wiener layer、KAN、AFMAE，和当前摘要一样显得散。
- 最后一句强调 `deep learning for real-time on-board computation`，容易把重点拉回 AI。

建议结论与新摘要同构：

1. 开头回到 MET 问题：本文面向 MET 大震级幅值相关频率响应漂移，建立硬件集成前馈补偿系统。
2. 中间总结系统机制：局部频响先验的 Wiener 线性层 + 受约束 KAN + LUT。
3. 后半段给关键结果：频漂、灵敏度漂移、线性度、STM32F405。
4. 末句收束到“不增加力反馈硬件的 MET 实时补偿”，避免泛化为通用 deep learning 结论。
